# v1.1.0 vocabulary architecture note

Planning only; v1.0.2 runtime behavior is unchanged by this note.

## EXPC-GVP

- Keep EXPC-GVP as an independent project.
- Fetch only explicit GitHub Releases and validate manifest, SHA-256, and schema.
- Start with manual updates, retain last-known-good data, and roll back on failure.
- Never ingest vocabulary silently.

## Dictionary Manager

Selectable layers: Global GVP, domain dictionaries, and Custom/User dictionary.
Each layer has an explicit enabled state and deterministic precedence.

## Custom Dictionary

Support create, edit, enable/disable, import, and export. Entries may define a
spoken form, canonical form, aliases, and corrections. User content is never
uploaded publicly by default.
